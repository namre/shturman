# Штурман

**Вы ведёте — он читает дорогу.** Личный ИИ-помощник руководителя в Telegram на вашем собственном сервере: читает выбранные вами чаты, помнит договорённости, по утрам присылает сводку и готовит черновики ответов. Один сервер — один человек.

Это пилот: на настоящих аккаунтах Telegram и с настоящими моделями проверено не всё (раздел «Что готово»).

**Агенту (Claude Code, Codex).** Вас попросили развернуть «Штурман» — хватит и ссылки на этот репозиторий — работайте по [`prompts/deploy-remote.md`](prompts/deploy-remote.md), если вы на компьютере владельца (сервер — по SSH, его готовите вы), или по [`prompts/deploy.md`](prompts/deploy.md), если вы на самом сервере; так, будто владелец вставил текст промпта: с первого пункта, со всеми его вопросами и стоп-точками. На компьютер, где вы запущены, «Штурман» не ставится, если владелец не назвал его своим сервером; неясно, где вы, — спросите. Сопровождать уже развёрнутый — [`prompts/operate-codex.md`](prompts/operate-codex.md). Правила для любой задачи — [`AGENTS.md`](AGENTS.md).

## Прежде чем ставить

<!-- owner-text -->
**Кто ещё видит переписку.** Провайдер ИИ-модели: законченные разговоры читаемых чатов уходят ему днём раз в час и ночью; ещё — найденное для ответов ассистента, черновики и, если включите, фото и документы. Агент, который ставит и обслуживает сервер, имеет права администратора: не читать переписку — его правило, а не замок, и всё увиденное уходит его провайдеру. Провайдер сервера видит сервер и его копии.

**Чужое сообщение может управлять ассистентом.** Текст в читаемом чате может пытаться заставить ассистента вынести переписку наружу: интернет у него есть. Пределы выдачи архива и защита от таких сообщений (по умолчанию выключена) это сужают, но не исключают.

**Что может уйти от вашего имени.** Отправка выключена, пока вы её не включите. По кнопке «В чат» текст ложится в поле ввода вашего чата — отправляете вы. Включите отправку и автоответ доверенным — он уйдёт без вашего нажатия. Дадите боту согласований право отвечать в ваших чатах — писать от вашего имени в обход выключателя сможет любой, у кого есть его ключ: вы в @BotFather, «Штурман» на сервере, администратор сервера, а у бота «в одно нажатие» — держатель посредника. Создавайте бота сами.

**Копии.** Сам «Штурман» снимает копию перед обновлением и по просьбе, не по расписанию; она лежит на том же сервере, не зашифрована и содержит вход в ваш Telegram. Включите автоматические копии у провайдера сервера; от закрытия аккаунта у него спасает только копия у другого.

**Тихая остановка.** Заведите внешнего сторожа — иначе о падении сервера узнаете по молчанию ассистента. В день без новостей сводки нет.

**Telegram** может ограничить подключённый аккаунт — риск ваш.

**Ассистент ошибается уверенно** — находит договорённости, которых не было. Перед действием сверьтесь с цитатой в карточке.

**Что решаете вы.** Вариант установки, адрес (через посредника — только если доверяете его держателю), какие чаты читать, включать ли отправку и дополнения. Ключи вводите сами в браузере, ссылки входа никому не пересылайте. До установки агент перескажет вам этот экран и дождётся вашего «да», как и на других важных шагах.

**Сколько стоит.** Сервер — по тарифу провайдера. Агент — отдельно, по вашей подписке на Claude или ChatGPT либо по ключу. Модель — по использованию; наш расчёт по тарифам, без живого счёта: 5–40 долларов в месяц с недорогой моделью и 15–120 с сильной, без кэша — до двух раз больше. Проверьте счёт через неделю.

## Как развернуть

**Сначала выберите вариант** — выбираете вы, агент обязан спросить до первого шага. Сменить позже можно отдельной процедурой. Бот согласований нужен в обоих вариантах.

| Вариант | Что вы получаете | Что нужно дополнительно |
|---|---|---|
| **Ассистент в Telegram** | Ассистент отвечает вам в Telegram, ведёт архив, готовит сводки и черновики; настройка в браузере | Адрес для входа: свой домен, адрес сервера или посредник — агент проверит сервер и посоветует ([`docs/address.md`](docs/address.md)) |
| **Только архив и согласования** | Ассистента нет: архив с поиском и обязательства, вопросы — из своего Codex CLI или Claude Code | Домен не нужен. Нужен ваш терминал: страница настройки открывается только через туннель с вашего компьютера, ключ к архиву вы забираете командой сами; для разбора обязательств — ключ модели ([`docs/standalone.md`](docs/standalone.md)) |

**Основной путь — агент делает всё сам.** Откройте Claude Code (в приложении Claude — режим работы с кодом) или Codex у себя на компьютере и вставьте текст из [`prompts/deploy-remote.md`](prompts/deploy-remote.md). От вас — ответы на вопросы, пара действий в панели провайдера сервера (и у регистратора домена, если он есть) по подсказкам агента и «да» на важных шагах. Сервера ещё нет — агент поможет выбрать и купить ([`docs/hosting.md`](docs/hosting.md)).

**Понадобится:** сервер с Ubuntu 24.04 (рекомендуется 8 ГБ памяти и 4 ядра); два бота, которых вы создаёте сами у @BotFather, — для разговора с ассистентом и бот согласований с кнопками «Да» и «Нет» (без ассистента — только второй); ключ OpenRouter или OpenAI либо подписка ChatGPT; ключи приложения Telegram с my.telegram.org, если подключаете свой аккаунт.

**После установки** агент даст одноразовую ссылку на мастер (имя и характер, модель, бот ассистента), а ссылку на страницу «Настройки Штурмана» (бот согласований, способ подключения переписки, чаты) — только когда вы сами попросите: кто её откроет, тот и настраивает ([`docs/setup.md`](docs/setup.md)). Ключи вы вводите там, а не в чат с агентом. Обновление — по [`UPGRADING.md`](UPGRADING.md).

## Что умеет (цель)

- **Архив** — свой аккаунт Telegram только на чтение с выбором чатов либо бот в бизнес-режиме для личных чатов и аккаунт помощника для групп; прошлое — выгрузкой из Telegram Desktop.
- **Ответы** — в пределах ваших правил; чтение личных данных и раскрытие собеседнику согласуются раздельно, решения — кнопками в боте согласований.
- **Помощник** — отдельный аккаунт на втором номере, «ассистент такого-то», для групп. Первым не пишет; отвечать от своего имени сможет, только если вы включите отправку.
- **Память** — дословный архив, страницы о людях и проектах, обязательства со ссылкой на сообщение ([`docs/memory.md`](docs/memory.md)).
- **Сферы** — «Работа», «Семья», папки Telegram; правило для ассистента, не замок ([`docs/spheres.md`](docs/spheres.md)).
- **Голосовые и «кружки»** — расшифровка на вашем сервере ([`docs/voice.md`](docs/voice.md)).
- **Системы организации** — через MCP, ассистент только клиент. **Имя и характер** — на выбор ([`docs/personas.md`](docs/personas.md)).

---

Дальше — справочник для агента и разработчика. Устройство: стоковый Hermes Agent, расширения к нему (плагины, скиллы, MCP) и сервис переписки с Postgres рядом; сервис с архивом ставится и без Hermes. Подключённые источники и клиенты обрабатывают данные по своим правилам ([`docs/architecture.md`](docs/architecture.md)).

## Опасности подробно

К экрану «Прежде чем ставить» — где подробности:

- **Модель:** что уходит провайдеру — [`docs/setup.md`](docs/setup.md), [`docs/media.md`](docs/media.md); без своей модели сервиса закрытие выдачи архива обработку не останавливает — [`docs/architecture.md`](docs/architecture.md), «Открытое ограничение», п. 4. Провайдеры работают не во всех странах и могут заблокировать аккаунт по региону. Расчёт расходов — [`docs/hosting.md`](docs/hosting.md), «Сколько стоит модель».
- **Внедрённые инструкции:** главный противник — ассистент в Hermes под чужой инструкцией; с терминалом и интернетом он может переслать выданное ему из архива, граница выдачи сужает объём и скорость и сообщает владельцу — [`docs/security-review.md`](docs/security-review.md), «Противники»; [`docs/architecture.md`](docs/architecture.md), «Граница „Штурмана“ вокруг Hermes»; [`docs/deferred.md`](docs/deferred.md), ОТ-19.
- **Оператор:** может прочитать секреты, сессии и переписку и выдать себе ссылки входа — [`docs/security-review.md`](docs/security-review.md), «Известные открытые риски».
- **Отправка:** «Черновик ответа» приходит без «Отправить», пока отправка выключена; включает её владелец на сервере, без своего бота согласований она не работает. Автоответ отличается от согласования черновика, новый источник и раскрытие проверяются отдельно; без своей модели сервиса текст автоответа может подменить держатель токена ассистента. Токен бота согласований есть у сервиса, администратора сервера, создателя бота, а у бота «в одно нажатие» — у держателя посредника — [`docs/architecture.md`](docs/architecture.md), «Открытое ограничение»; [`docs/approvals-bot.md`](docs/approvals-bot.md). Первая настоящая доставка — [`docs/runbooks/validate.md`](docs/runbooks/validate.md).
- **Без бота согласований** ассистент отвечает и архив читается, но запросы, которые подтверждает владелец (принять обязательство, включить чтение чата, импорт), отклоняются, а отправка не включается — [`docs/architecture.md`](docs/architecture.md), «Без своего бота согласований». Поэтому бот — первый шаг страницы «Настройки Штурмана» в обоих вариантах установки.
- **Копии** — в них `.env`, сессии, токены и вся переписка; восстановление из копии провайдера не проверялось; куда класть вторую — [`docs/deployment.md`](docs/deployment.md), «Резервные копии»; [`docs/hosting.md`](docs/hosting.md), «Копии и „сервер исчез“».
- **Тихая остановка** — [`docs/deployment.md`](docs/deployment.md), «Сбои ловит система»; [`docs/runbooks/symptoms.md`](docs/runbooks/symptoms.md).
- **Аккаунт Telegram:** вход через сессию — не официальный механизм для ботов; сервис только читает, но файл сессии — полный доступ к аккаунту. Аккаунт помощника — автоматизация пользовательского аккаунта, особенно рискованная на новом номере.
- **Защита от внедрённых инструкций** — не гарантия, на настоящей переписке прятала в основном обычные сообщения — [`docs/guard.md`](docs/guard.md).
- **Посредник:** держатель может подменить имя и показать поддельную страницу настройки — [`docs/relay.md`](docs/relay.md).

## Что понадобится

- **Сервер:** минимум 4 ГБ — тяжёлые дополнения по одному; для голосовых — x86-64; диск от 40 ГБ и около 4 ГБ под распознавание речи ([`docs/voice.md`](docs/voice.md), «Какой сервер нужен»). Что и откуда скачивается — [`docs/deployment.md`](docs/deployment.md). Нет прямого доступа к Telegram или провайдеру модели — исходящий прокси.
- **Адрес:** домен (страница настройки — порт 8443 или отдельное имя), IP-адрес сервера (порт 80, только IPv4) или посредник по коду приглашения — [`docs/address.md`](docs/address.md).
- **Модель:** штатные настройки Hermes — ключ или вход по подписке, проверки — [`docs/target-model.md`](docs/target-model.md); своя модель сервиса и вариант без Hermes — ключ провайдера с API, совместимым с OpenAI, или подписка ChatGPT.
- **Telegram:** `api_id` и `api_hash` с my.telegram.org для входа в аккаунт; для помощника — второй номер. Premium для бизнес-режима не нужен ([`docs/setup.md`](docs/setup.md)).

## Другие способы развёртывания

**Агент на сервере** — для тех, кто сам работает с SSH: Claude Code или Codex CLI на сервере, репозиторий в `/opt/shturman` (образец прокси ждёт этот путь). Команда — для самого сервера, не для вашего компьютера:

```
sudo install -d -o "$USER" /opt/shturman && git clone https://github.com/namre/shturman.git /opt/shturman && cd /opt/shturman && ./ops/install-ref.sh
```

Затем [`prompts/deploy.md`](prompts/deploy.md) или [`prompts/deploy-standalone.md`](prompts/deploy-standalone.md); runbook — [`docs/runbooks/`](docs/runbooks/). **Обычный чат, у которого нет доступа к серверу**, — [`prompts/guided-chat.md`](prompts/guided-chat.md): команды в терминале сервера выполняете сами. **Сопровождение** — [`prompts/operate-codex.md`](prompts/operate-codex.md). Облачные агенты в своей песочнице до сервера не дотянутся; ключ доступа к серверу в облако не отдавайте.

## Что готово

Стенд — тесты и стенд разработки с подставными Telegram и моделью; живой — эталонный сервер или настоящий Telegram. Версия — в файле `VERSION`.

| Часть | Состояние |
|---|---|
| Документы, [`AGENTS.md`](AGENTS.md), стартовые промпты | Есть |
| `compose.yaml` со стоковым Hermes, скрипты `ops/` | Hermes 0.21.5 поднят на эталонном сервере (Ubuntu 24.04); стек целиком — только на стенде ([`docs/deployment-checks.md`](docs/deployment-checks.md)) |
| Runbook развёртывания | Черновики; шаги 1–4 режима с Hermes пройдены на живом сервере |
| Плагин: вход, привязка владельца, мастер; страница «Настройки Штурмана» на своём адресе | Стенд в браузере; с настоящим аккаунтом и на эталонном сервере — нет ([`docs/setup.md`](docs/setup.md)) |
| Сервис переписки: архив, импорт, сессии, поиск, архив для агента (MCP), граница выдачи архива | Тесты, частично стенд; с настоящим Telegram — нет ([`docs/service-checks.md`](docs/service-checks.md)) |
| Свой бот согласований, своя модель сервиса | Бот работает вживую; доставка ответа собеседнику, ещё несколько путей бота и подписка ChatGPT вживую не проверены; бот «в одно нажатие» — стенд ([`docs/approvals-bot.md`](docs/approvals-bot.md)) |
| Черновики ответов, «В чат», задачи ответа | Отправка выключена; «В чат» вживую проверен частично ([`docs/runbooks/validate.md`](docs/runbooks/validate.md)) |
| Память, обязательства, ночная обработка; сводка и обзор недели | Тесты с подставной моделью; на живом экземпляре — два первых прогона договорённостей, качество не измерено ([`docs/memory.md`](docs/memory.md)) |
| Приложение «Штурман» в Telegram | Стенд; в настоящем Telegram не открывалось ([`docs/miniapp.md`](docs/miniapp.md)) |
| Сферы, шаг 1 | Стенд ([`docs/spheres.md`](docs/spheres.md)) |
| Поиск по смыслу, разбор фото и документов, голосовые, защита | Выключены по умолчанию; стенд ([`docs/search.md`](docs/search.md), [`docs/media.md`](docs/media.md), [`docs/voice.md`](docs/voice.md), [`docs/guard.md`](docs/guard.md)) |
| Режим без Hermes | Стенд ([`docs/standalone.md`](docs/standalone.md)) |
| Обновление, восстановление, копии на другой диск | Стенд и CI; выпуски пока кандидатами `-rc` ([`docs/releases.md`](docs/releases.md)) |
| Сбои ловит система, сообщения о новых версиях | Стенд ([`docs/runbooks/symptoms.md`](docs/runbooks/symptoms.md)) |
| Без домена: HTTPS по IP | Сертификат получен на живом сервере; с внешнего компьютера страница входа и «Настройки Штурмана» по IP открываются (коды ответа), вход в дашборд до конца — нет ([`docs/address.md`](docs/address.md)) |
| Посредник `sh.namre.app` | Стенд и временные экземпляры вживую; постоянно не работает ни один ([`docs/relay.md`](docs/relay.md)) |
| Внешние источники, внешний архив по OAuth | Код есть, выключено ([`docs/external-sources.md`](docs/external-sources.md), [`docs/remote-mcp.md`](docs/remote-mcp.md)) |

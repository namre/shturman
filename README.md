# Штурман

**Вы ведёте — он читает дорогу.** Личный ИИ-помощник руководителя в Telegram на собственном сервере. Работает поверх стокового Hermes Agent как набор расширений и один сервис рядом; сервис с архивом можно поставить и без Hermes. Читает и помнит переписку владельца в Telegram, готовит ответы, следит за договорённостями и поручениями. Один экземпляр — один человек; данные не покидают сервер владельца, кроме запросов к выбранному провайдеру модели.

> **Статус: 0.0.4, проектирование и спайк.** Законченного ассистента в репозитории пока нет. Написаны и покрыты тестами вход, мастер первой настройки, сервис переписки с архивом, поиском, обязательствами и страницами о людях, свой бот согласований сервиса, защита от внедрённых инструкций и режим установки без Hermes. С настоящим Telegram и настоящей моделью сервис переписки ещё не проверялся; под Docker стек запускался только на стенде разработки; экранов для переписки в кабинете нет. **Отправка сообщений выключена.** Что именно готово — в таблице ниже.

## Что умеет (цель)

- **Бизнес-бот Telegram** — видит личные чаты владельца, готовит черновики ответов; отправка только после подтверждения.
- **Дополнительный Telegram-аккаунт** — «ассистент такого-то»: пишет первым, напоминает о сроках, собирает документы, работает в группах.
- **Импорт истории** — экспорт из Telegram Desktop превращается в архив с поиском.
- **Память** — дословный архив переписки и поверх него страницы о людях и проектах и список обязательств, каждое утверждение со ссылкой на исходное сообщение.
- **Связь с системами организации** — через MCP, ассистент выступает только клиентом.
- **Имя и характер на выбор** — Штурман, Нестор, Савельич, Бэрримор, Дживс или своё; только в разговоре с владельцем.

## Как развернуть

Проект рассчитан на то, что развёртывание и сопровождение выполняет ИИ-агент под вашим присмотром.

**Режим «агент исполняет»** — Claude Code или Codex CLI запущен на самом сервере по SSH:

```
git clone <адрес репозитория> shturman && cd shturman
```

затем дайте агенту текст из `prompts/deploy.md`. Агент пойдёт по `docs/runbooks/deploy.md`: проверит сервер, поднимет стек командой `./ops/up.sh` и выдаст вам ссылку для первого входа.

**Режим «агент ведёт, вы вставляете»** — обычный чат (ChatGPT, Claude): дайте ему текст из `prompts/guided-chat.md` и выполняйте команды сами.

Облачные агенты, работающие в собственной песочнице, до вашего сервера не дотянутся; SSH-ключ от сервера в облако не отдавайте.

**Без Hermes.** Если разговаривать с ассистентом в Telegram не нужно, а нужен архив переписки с поиском и список обязательств, экземпляр ставится в режиме «только архив и согласования»: дайте агенту текст из `prompts/deploy-standalone.md`, он пойдёт по `docs/runbooks/deploy-standalone.md`. Вопросы по архиву вы задаёте из своего Codex CLI или Claude Code. Чего в этом режиме нет — `docs/standalone.md`.

Обновление установленного экземпляра — по `UPGRADING.md`.

## Что понадобится

- Чистый сервер Linux: от 4 ГБ памяти, от 40 ГБ диска. Поиск по смыслу добавляет около 1,2 ГБ памяти, защита от внедрённых инструкций — около 0,6 ГБ; уместится ли всё вместе в 4 ГБ, ещё не проверено.
- Адрес (домен), по которому вы будете открывать ассистента в браузере.
- Бот от @BotFather: мастер настройки подскажет, как его создать. Его токен, как и остальные ключи, вы вводите в браузере, а не в терминале.
- Доступ к модели: ключ OpenRouter или OpenAI либо подписка ChatGPT.
- Для дополнительного аккаунта и для чтения основного: собственное приложение Telegram (`api_id`, `api_hash` с my.telegram.org); для дополнительного — ещё и отдельный номер.
- Если с сервера нет прямого доступа к Telegram или провайдеру модели — исходящий прокси.
- Для своего бота согласований — ещё один бот от @BotFather, отдельный от бота ассистента. Его токен вы вводите сами в терминале сервера, скрытым вводом.
- Для режима без Hermes домен не нужен; нужны отдельный бот от @BotFather и ключ провайдера модели с API, совместимым с OpenAI, — их вы тоже вводите в терминале сервера скрытым вводом.

## О чём нужно знать заранее

- **Дополнительный аккаунт — автоматизация пользовательского аккаунта Telegram.** Telegram может его ограничить, особенно новый номер. Риск несёте вы.
- **Провайдеры моделей работают не во всех странах** и могут блокировать аккаунт при доступе из неподдерживаемого региона. Проверьте условия своего провайдера.
- **Вы обрабатываете переписку других людей.** Требования закона о персональных данных в вашей стране — ваша ответственность.
- **Отправка сообщений выключена.** В версии 0.0.4 ассистент не отправляет ничего и никому, пока вы сами не включите отправку на сервере. Без своего бота согласований она не включается вовсе; со своим ботом главная дыра закрыта, но путь не проверен на настоящем Telegram, и включать её пока не следует (`docs/architecture.md`, «Открытое ограничение»). Когда отправка заработает, от вашего имени сообщение будет уходить только после вашего подтверждения; исключение — автоответ людям из списка доверенных, который вы включаете отдельно.
- **Защита от внедрённых инструкций — не гарантия.** Модель ловит большинство грубых попыток управлять ассистентом через входящее сообщение и пропускает заметную часть тихих. Измеренные числа — `docs/guard.md`.

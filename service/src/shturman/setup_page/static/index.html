                                    Своя модель сервиса

                                    Раз в сутки сервис разбирает новые сообщения: находит договорённости и обновляет заметки о людях. Для этого нужна языковая модель. Если сервис работает вместе с ассистентом в Telegram, разбор делает ассистент своей моделью, и отдельный доступ не обязателен. Здесь можно дать сервису собственный доступ к модели — тогда он обращается к ней сам. Способов два: подписка ChatGPT или ключ API. Действует один из них.

                                    Ключ модели задан в настройках сервера. Изменить его можно только там.

                                    Подписка ChatGPT

                                    Если у вас есть подписка ChatGPT Plus или Pro, сервис может пользоваться ею вместо ключа API: вы входите в ChatGPT и разрешаете «Штурману» доступ. Лимиты подписки общие с вашей обычной работой в ChatGPT. Если у вас есть ассистент в Telegram, подписку для него подключают в его мастере настройки; здесь — модель самого сервиса.

                                    Список даёт OpenAI для вашей учётной записи.

                                    Лимиты
                                    1. В новой вкладке откроется ChatGPT. Войдите в свою учётную запись и разрешите доступ.
                                    2. После этого браузер покажет ошибку вроде «Не удаётся получить доступ к сайту» или «127.0.0.1 отклонил подключение». Так и должно быть: сервис работает на сервере, а не на вашем компьютере.
                                    3. Скопируйте весь адрес из адресной строки той вкладки — он начинается с http://127.0.0.1:1455/auth/callback — и вставьте его сюда.

                                    Ключ API провайдера модели

                                    Ключ провайдера с API, совместимым с OpenAI: OpenAI, OpenRouter и подобные.

                                    Оставьте пустым для OpenAI. Для OpenRouter — https://openrouter.ai/api/v1.

                                    Как его пишет провайдер, например gpt-4o-mini.

                                    • Перед сохранением сервис задаст модели один короткий вопрос — так проверяется ключ.
                                    • Адрес — только https:// и только в интернете. Адреса самого сервера и домашней сети страница не принимает.
                                    • Если меняете адрес, ключ нужно вставить заново: сохранённый ключ на новый адрес не отправляется.
                                    • Локальную модель (например, Ollama) отсюда подключить нельзя. Её адрес задаёт тот, кто обслуживает сервер, — в настройках сервера; здесь такой адрес не меняется.
                                    • Ключ API и подписка ChatGPT друг друга заменяют: сохранение ключа выключает подписку.

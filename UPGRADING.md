# Обновление

Этот файл читает ИИ-агент перед обновлением экземпляра. На каждую версию, требующую действий, здесь будет раздел одной формы:

- **С какой версии на какую.**
- **Что меняется** для владельца.
- **Перед началом:** резервная копия и её проверка (стоп-точка).
- **Шаги** — каждый с командой, ожидаемым выводом и проверкой.
- **Откат** — как вернуться на прежнюю версию.

Обновление всегда идёт по одной версии за раз, без перескоков.

## 0.0.x

Данных и работающего стека ещё нет; обновление — `git pull`.

## 0:35–1:35 — Как работает

Четыре эпизода по 15 секунд, перед каждым — титр.

**Вопрос к переписке.** «Что решили с подрядчиком по фасадам?» → «Оплата после приёмки. 3 октября срок перенесли на пятницу» и две ссылки на исходные сообщения.

**Голос:** «Вопрос к переписке — ответ со ссылками на исходные сообщения».

**Сводка и поручения.** Утренняя сводка: обещали вам, обещали вы, просрочено. Карточка «Петров — смета по фасадам — до пятницы» с кнопками «Принять» и «Отклонить».

**Голос:** «Утром — сводка. Найденное поручение попадает в список после вашего „Принять“».

**Напоминание сотруднику.** Аккаунт «Помощник» пишет Петрову: «Напоминаю: смета по фасадам до пятницы». Подпись «Макет».

**Голос:** «Напоминает отдельный аккаунт помощника. Сначала — по вашему нажатию, затем — по утверждённым шаблонам».

**Ответ от вашего имени.** Черновик в боте согласований, кнопки «Отправить», «Изменить», «Отклонить».

**Голос:** «От вашего имени — только черновики. Отправка — по вашему нажатию».
